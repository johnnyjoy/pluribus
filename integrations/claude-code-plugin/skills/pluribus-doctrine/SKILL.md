# Doctrine (short)

- Memory is addressed by **tags + situation**, not mandatory project/workspace partitions.
- **Recall** pulls ranked, governed bundles; **record** feeds advisory / probationary ingest—**ranking and promotion stay on the server**.
- The Claude Code plugin and hooks **orchestrate** (reminders, HTTP preview, MCP wiring); they **do not** duplicate policy.

If Pluribus MCP is **not** in the tool list, state that once and proceed without pretending tools ran.

Full reference: repository **`docs/memory-doctrine.md`** and **`integrations/pluribus-instructions.md`**.
