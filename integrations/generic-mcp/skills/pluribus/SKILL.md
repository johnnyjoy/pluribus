# Pluribus Skill

## Loop

1. **`wakeup_context`** or **`recall_context`** (before work)
2. If **`housekeeping`** or open chores → **`resolve_chore`** with **`agent_id`** (see [pluribus-instructions.md](../../../../pluribus-instructions.md))
3. plan / act
4. If recall surfaced memories you used or rejected → **`memory_feedback`**
5. **`record_experience`** (after outcome)

## Use When

- Any non-trivial task
- Debugging
- Repeated issues
- Learning new patterns

## Principle

If you do not recall, you risk repeating mistakes.  
If you do not record, you lose what you learned.
