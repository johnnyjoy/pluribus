# Extension icon

**`icon.png`** is a **128×128** square derived from the official **`Pluribus_logo.png`** at the **repository root** (same asset the main **README** uses).

Regenerate after logo updates:

```bash
cd integrations/vscode/extension
npm run icons
```

Do not replace with arbitrary artwork — keep it aligned with the product mark in **`Pluribus_logo.png`**.
